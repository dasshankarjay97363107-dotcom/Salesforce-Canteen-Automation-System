# 🚀 Salesforce Canteen Automation System

## 📌 Project Overview

The **Salesforce Canteen Automation System** is a Salesforce Admin project designed to manage customers, orders, payments, and deliveries using Salesforce declarative features.

The project focuses on **Salesforce Administration, Business Process Automation, Reports, and Dashboards**.

---

## 🎯 Project Objective

The main objective of this project is to digitize canteen operations and automate important business processes such as:

- Customer registration
- Order management
- Order approval
- Payment tracking
- Delivery management
- Email notifications
- Business reporting

---

## 🏗️ Salesforce Data Model

The project contains the following custom objects:

- 👤 Customer
- 🛒 Order Details
- 📋 Order Summary
- 💳 Payment
- 🚚 Delivery

Relationships between these objects are configured to maintain and connect business data.

---

## ⚙️ Salesforce Admin Features

### 🔹 Custom Objects & Fields

Created custom objects and fields to manage customer, order, payment, and delivery information.

### 🔹 Validation Rules

Implemented validation rules to prevent invalid data entry and maintain data quality.

### 🔹 Formula Fields

Created formula fields for automatically calculated business information.

### 🔹 Approval Process

Implemented an Order Approval Process to control and manage order approval.

### 🔹 Salesforce Flow

Created Record-Triggered Flows for business automation.

#### Customer Registration Flow

Customer Created  
↓  
Record-Triggered Flow  
↓  
Registration Email Sent

#### Order Approval Flow

Order Updated  
↓  
Order Status = Approved  
↓  
Approval Email Sent

#### Delivery Success Flow

Delivery Updated  
↓  
Delivery Status = Delivered  
↓  
Delivery Confirmation Email Sent
