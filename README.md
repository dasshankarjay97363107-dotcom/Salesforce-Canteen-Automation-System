# Salesforce Canteen Automation System

## 📌 Project Overview

The Salesforce Canteen Automation System is a Salesforce Admin
project designed to manage customers, orders, payments and
deliveries using Salesforce declarative features.

The project demonstrates how Salesforce can be used to automate
real-world canteen business processes without custom Apex or LWC.

---

## 🎯 Project Objective

The main objective of this project is to digitize canteen operations
and automate customer registration, order approval, payment tracking
and delivery management.

---

## ⚙️ Salesforce Admin Features

- Custom Objects
- Custom Fields
- Object Relationships
- Validation Rules
- Formula Fields
- Approval Process
- Record-Triggered Flows
- Reports
- Lightning Dashboard
- Lightning App Builder

---

## 🔄 Automation

### Customer Registration

Customer Created  
↓  
Record-Triggered Flow  
↓  
Registration Email Sent

### Order Approval

Order Updated  
↓  
Order Status = Approved  
↓  
Approval Email Sent

### Delivery

Delivery Updated  
↓  
Delivery Status = Delivered  
↓  
Delivery Confirmation Email Sent
